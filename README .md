# Análisis de Incidencia Delictiva en México

## Descripción

Proyecto de análisis exploratorio de datos de incidencia delictiva en México utilizando Python.

El objetivo es explorar la información disponible para identificar tendencias, comportamientos y patrones mediante técnicas de manipulación, agrupación y visualización de datos.

## Objetivos

- Analizar la evolución de los delitos reportados a través del tiempo.
- Comparar el comportamiento de la incidencia delictiva entre diferentes años.
- Analizar la información relacionada con las víctimas.
- Examinar la distribución de víctimas por rango de edad.
- Saber cuales son los delitos más frecuentes.
- Utilizar visualizaciones para facilitar la interpretación de los resultados.
- Obtener conclusiones a partir del análisis de los datos.

## Tecnologías utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

## Proceso de análisis

### 1. Exploración de los datos

Se realizó una exploración inicial de los conjuntos de datos para conocer su estructura, variables disponibles y características principales.

### 2. Manipulación y procesamiento

Se utilizaron herramientas de Python para organizar, transformar y analizar la información.

Entre las operaciones realizadas se incluyen:

- Agrupación de datos.
- Conteo de registros.
- Análisis de variables.
- Organización de información para su representación gráfica.
- Cálculo de indicadores.

### 3. Visualización de los cinco delitos más frecuencia

Se realizo el análisis de cuales son los delitos con mayor frecuencia reportados.

### 4. Análisis temporal

Se analizó el total de delitos reportados por año para observar su comportamiento a través del tiempo.

También se construyó un índice tomando como referencia el año 2015, establecido como base 100, para facilitar la comparación de la evolución de los delitos.

### 5. Análisis de víctimas

Se analizó la distribución de víctimas de acuerdo con diferentes rangos de edad.

Los rangos considerados incluyen:

- Menores de edad (0-17)
- Adultos (18 y más)
- No especificado
- No identificado

### 6. Visualización

Se utilizaron gráficas para representar los resultados para facilitar la identificación de tendencias y diferencias entre los grupos analizados.
